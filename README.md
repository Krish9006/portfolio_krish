# Krish Gupta — Portfolio

Personal portfolio built with Next.js (App Router), Tailwind CSS v4 and Framer Motion.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

## Structure

- `app/` — layout, global styles, page composition
- `components/` — one component per section (Hero, Projects, About, Skills, Experience, Services, Contact)
- `lib/content.js` — all copy and data (projects, skills, background, contact). Edit content here, not in components.
